Repo Radio

A git history, played back as music. Every commit is one bar: the author picks the instrument, the language picks the scale and the size of the change sets how busy it gets.

Make a score with repo-radio ./your-repo --format json, then open the .score.json file here or drop it anywhere on this page. The file is read in your browser and never uploaded.

Who plays what

    On the dial, a taller mark is a bigger commit. A dot on top is a merge, a flag is a tag and a mark hanging below the line is a revert. Click the dial to jump, or focus it and use the arrow keys to step between commits.
